Fuentes de imágenes que no se publican tal cual: las redes no aceptan SVG, así que se exportan a PNG.

- `og-cover.es.svg` → `public/og-cover.png`
- `og-cover.en.svg` → `public/og-cover-en.png`

Se exportan a 1200×630 abriendo el SVG en Chromium (las fuentes vienen de Google Fonts) y tomando una captura. Solo texto y el automapa: sin foto.
`public/apple-touch-icon.png` (180×180) se exporta desde `public/favicon.svg`.
